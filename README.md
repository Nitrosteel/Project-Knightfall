# Welcome to Project: Knightfall's GitHub repository!

Hi, Nitrosteel here. If you're reading this, then I'm guessing you can't wait to get your hands on the next feature update for Project: Knightfall, the ambitious Starbound mod that adds overpowered weapons and snazzy looking props.
The instructions can be found below.

Don't worry, Knightfall as a project **isn't dead**, but it is taking a while to cook the next update. Contributions and suggestions are always welcome tho, and I take any help I can get.

## How to get Project: Knightfall Github version:

> [!WARNING]
> Before you download anything, you **MUST unsubscribe to Workshop Knightfall first**. Not doing so will cause conflict. Don't worry, as long as you don't open the game after unsubbing, your items should be fine.
> Be wary that **installing GitHub Knightfall will cause you game to crash on the first launch of the game**. However, it will be fine on subsequent launches.
> This is because _some_ items in the GitHub version have been **permanently removed**, which Starbound won't recognize anymore in your save and will throw an exception during the first launch. It will turn them into Perfectly Generic Items on your next launch. 

### If you want a stable release:
Get a beta release here: https://github.com/Nitrosteel/Project-Knightfall/archive/refs/tags/1.8.0.2.zip
1. Click on `[> Assets]`
2. Click on `[Source code (zip)]` to begin the download.
3. Extract the contents of the zip file to your `/mods` folder in your Starbound folder. You can also paste the entire zip file to your `/mods` folder directly.

### If you want the bleeding edge version:
1. Navigate to the top of this page until you see the green `[Code]` button. Click on that button.
2. Click `[Download as .zip]` to begin the download.
3. Extract the contents of the zip file to your `/mods` folder in your Starbound folder. You can also paste the entire zip file to your `/mods` folder directly.

> [!IMPORTANT]
> There are _two branches_ you can pick from if you choose the bleeding edge version - **master** and **improved-weapons**.
> You can select what branch to pick on the top left corner of the screen. Look for a label called [master].
> Improved-weapons contains the same updates as master, except that a few weapons have been altered with even better sprites, and new gameplay. 

Congratulations! You now have Github Knightfall!
